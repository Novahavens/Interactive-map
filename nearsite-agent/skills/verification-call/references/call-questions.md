# Call questions and where each answer goes

| Ask | Field |
|---|---|
| Free from move-in to move-out? | available_from, available_to |
| Monthly rent; utilities included, any cap | owner_monthly, utilities_included, utility_cap_owner |
| Refundable deposit | owner_deposit |
| Cleaning fee, pet fee, other one-time fees | owner_clean, owner_pet_fee, owner_other_fees |
| These pets (breed, weight) OK? Limits? | pets_ok, pet_limits |
| Bedrooms, bed sizes, bathrooms | bedrooms, bed_sizes, bathrooms |
| One level, or stairs? Floor if an apartment | single_level, floor |
| Parking spaces, covered, garage | parking_spaces, parking, garages |
| Linens, towels, kitchen, washer and dryer, Wi-Fi | amenities |
| Landlord's notice to vacate, minimum stay | landlord_notice_days, min_stay_days |
| OK with a corporate lease paid by Nova Havens? | corporate_lease_ok |
| Email for the written terms | landlord_email |
| Photos link | photos_url |
| Exact street address with unit | address, unit |
