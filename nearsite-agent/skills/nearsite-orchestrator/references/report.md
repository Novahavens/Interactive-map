# Run report shape

Open with what needs a person, then one line per claim. Plain words, no ids a person can't use.

```
2 claims need you:
1. Fictionville 3 BR (request 90002): pet breeds and weights unknown for 4 dogs. Ask the adjuster.
2. Exampleburg 2 BR (request 90003): 1 home verified and ready for William and Lou to approve.

- Sampleton 3 BR (90001): our database had 1 home and it's too small, so I found 2 outside homes; both need a tick or X.
- Fictionville 3 BR (90002): 17 of 20 homes ticked as fits; 3 take no pets.
```

Also write `run.json` in the run folder: per claim, stage, homes with status and blockers, and every message, task, payload and card that would have gone out.
