# Storylines (29 Oct 2026)

Built straight through on request, so the recommendation was taken.

## A. One claim, start to finish (picked)

Device: the worked example. Form: one continuous world, the real app full frame, the camera pushing into the part the voice names.
A searcher picks the Rivera family's claim and takes it all the way: find, check, call, owner said, edit, add, send.
Each function is one beat, and each beat ends on what no longer has to be done by hand.
First 2 s: the map already lit with green, yellow and red pins around one amber loss pin, the line "A family can't stay in their home tonight."
Beats: hook → pick → claim card → find → colours → status → fit and cost → call/text → call log → owner said → edit → add → send → phone → close.
Look: the app's own light canvas (#fafafa, hairlines, Geist), the amber loss colour as the only accent.
Sound: a bright, mid-tempo SaaS bed kept low under the voice, lifting once at the close; soft clicks on real clicks.

## B. Before and after

Device: life before and after. Form: split screen to one. Each task opens on the old way (Monday board, tabs, a notepad), then collapses into the map doing it.
Left out: it shows the old tools more than the new one, and a tutorial needs time in the app.

## C. A house's day

Device: one object across the story. Form: object-to-object chain. Follow one property from a Monday row to a pin, a call, an owner's words, an edit, a claim and an email.
Left out: bolder, but it skips Pick and the claim card, which every new searcher needs first.
